# LdapAdapter

- Используется для взаимодействия с сервером кафедры по протоколу LDAP.

Должен реализовывать следующие методы:

## **ValidatePassword(login, password) -> bool**

Делает запрос к серверу кафедры для валидации пароля.

## **GetInfo(login) -> LdapUserInfo**

Делает запрос к серверу кафедры для валидации пароля.

# StorageAdapter

- Использует для взаимодействием с файловым хранилищем сервера.

Должен реализовывать следующие методы:

## **UploadFile(file, file_name) -> error**

Сохраняет файл с заданным именем в файловое хранилище, если файл с таким именем уже существует, возвращает ошибку.

## **GetFile(file_name) -> file, error**

Получает файл по названию. nil, если файл не найден.

## **DeleteFile(file_name) -> error**

Удаляет файл по названию, возвращает ошибку или nil.

## **UploadPicture(file, file_name, login) -> str, error**

Загружает файл в отдельное хранилище (другая дирректория открытая для просмотра), создает в нем дирректорию с именем login, имя файла это file_name + соль + исходное расширение 
Возвращает новое имя файла и ошибку

## **DeletePictures(login) -> error**

Удаляет дирректорию в отдельном файловом хранилище с именем логин.
